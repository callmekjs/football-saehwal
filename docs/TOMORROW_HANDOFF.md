## 2. final_eval 최종 평가

작업 트리가 깨끗한 상태에서 `final_eval`을 단독으로 실행한다.

- 브라우저에서 처음부터 감독 보고서까지 한 경기를 직접 완주한다.
- 전술 변경이 실제 선수 움직임과 경기 계산에 반영되는지 확인한다.
- 오프사이드 판정, 정보량, 한국어 문체, 감독 보고서의 실제 경기 근거를 본다.
- 세 플레이테스트 보고서의 중대 항목을 직접 재현한다.
- 기계 검사와 밸런스 검증을 직접 다시 실행하고 100점 만점으로 채점한다.

`final_eval`은 코드를 고치지 않는다. 80점 미만이면 담당 에이전트용 수정
지시문을 받아 고친 뒤 다시 평가한다. 80점 이상이면 Vercel 배포 준비로 간다.
