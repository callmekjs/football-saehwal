# 출처와 라이선스

> 이 프로젝트에 들어간 **외부 자산**을 전부 적는다. 심사에서 출처를
> 물어보면 이 파일을 보여주면 된다.
>
> 대회 규칙: *"타인의 결과물을 무단 복제·도용하거나 라이선스를 위반한
> 경우 실격 또는 감점될 수 있습니다."*

## 원칙

1. **출처가 확실하지 않으면 안 쓴다.** 애매하면 직접 만든다.
2. **유튜브에서 받지 않는다.** 그쪽 이용약관이 다운로드를 금지하고,
   올라온 것 대부분은 원저작자가 따로 있다. 사용자가 허락해줄 수 있는
   권리가 아니다.
3. **출처 표기가 필요한 것은 되도록 피한다.** 표기를 빠뜨리면 그것만으로
   라이선스 위반이 된다. CC0 처럼 표기 의무조차 없는 것을 먼저 찾는다.
4. 그래도 쓰게 되면 **이 파일에 반드시 적는다.**

## 소리

| 파일 | 내용 | 라이선스 | 출처 |
|---|---|---|---|
| `public/sound/whistle.wav` | 심판 휘슬 | **CC0 1.0** (저작권 전면 포기, 표기 의무 없음) | [위키미디어 공용](https://commons.wikimedia.org/wiki/File:218318_splicesound_referee-whistle-blow-gymnasium.wav) · 원작 SpliceSound, [Freesound #218318](https://freesound.org/people/SpliceSound/sounds/218318/) |

**함성·기타 효과음은 파일이 아니라 코드다.** `src/ui/sound.ts` 가 Web
Audio 로 파형을 직접 합성한다. 외부 자산이 아니므로 라이선스가 없다.

## 선수·구단 데이터

**없다.** 실존 선수 이름·사진·구단 엠블럼·유니폼을 하나도 쓰지 않는다.
선수는 등번호와 능력치뿐인 창작 데이터이고 `Player` 타입에 이름 칸 자체가
없다(`src/sim/squad.ts`). 저작권 회피만이 이유가 아니다 — 이 시뮬레이션은
구조상 "가장 느린 수비수"를 실점 원인으로 기계적으로 지목하므로, 실명이
붙으면 특정 선수 비하가 자동으로 생산된다.

## 참고만 한 것 — 코드는 가져오지 않았다

`ZOXEXIVO/open-football` (Apache-2.0, Rust). 사용자가 참고하라고 지정했다.

- **코드를 한 줄도 가져오지 않았다.** 저장소를 clone 하지 않았고 자료구조·
  상수 표·주석을 옮겨 적은 곳이 없다.
- 가져온 것은 개념 한 문장이다 — "지금 무엇을 하는 중인가가 속도 상한을
  정한다." 방법이지 표현이 아니라 저작권 대상이 아니다.
- **그쪽 데이터베이스는 쓰지 않는다.** 실존 구단·선수 실명이 들어 있다.
- 화면 쪽도 **정보 배치 원칙만** 참고했고 코드·CSS·색·문구·이미지는
  복사하지 않았다.

## 글꼴

시스템 글꼴만 쓴다(`system-ui`). 웹폰트를 내려받지 않으므로 글꼴
라이선스가 걸릴 것이 없다.
