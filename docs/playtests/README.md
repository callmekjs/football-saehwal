# 세 페르소나 플레이테스트

세 보고서는 같은 깨끗한 HEAD를 서로 다른 사용자 관점에서 직접 플레이한
기록이다.

- `fan.md` — 축구 매니아
- `casual.md` — 축구에 관심이 중간 정도
- `newcomer.md` — 축구에 관심이 전혀 없음

각 플레이테스터는 자기 파일의 맨 위에 최신 회차를 추가한다. 세 보고서가
모두 끝나고 보고서만 커밋된 깨끗한 트리에서 `final_eval`을 부른다.
`final_eval`은 보고를 그대로 믿지 않고 차단·중대 발견을 직접 재현한 뒤
담당 에이전트용 수정 지시를 만든다.
