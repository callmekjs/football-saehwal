# 축구 사활

**상태 벡터 기반 실시간 축구 전술 퍼즐**

바둑의 사활문제를 축구로 옮긴 웹 게임입니다. 창작된 경기 국면 하나를 주고, **75초 안에** 그 판을 풀어내게 합니다.

> 후반 80분, 1-0으로 이기고 있는데 우리 팀 한 명이 퇴장당했다. 교체 카드는 2장. **이 판을 지켜낼 수 있는가.**

- 월간 해커톤 · "내가 축구 감독이라면"
- 1인 개발 (기획 · 개발 · 밸런싱 · 배포)
- 개발 기간: 2026.07.27 ~ 2026.08.03

---

## 무엇이 다른가

**시계가 멈추지 않습니다.** 일시정지가 없고, 고민하는 동안에도 상대는 공격하며 우리 선수의 체력은 소모됩니다. 멈춘 화면에서 최선을 고르는 것은 분석가의 일이고, 흐르는 경기에 개입하는 것이 감독의 일이라고 보았습니다.

**되돌릴 수 없습니다.** 교체 카드는 유한하고 회수할 수 없습니다. 내린 결정은 취소되지 않습니다.

**결과와 판단을 분리해서 채점합니다.** 축구는 확률 게임이라 옳게 판단하고도 무너질 수 있습니다. 그래서 이진 결과(지켜냈다 / 무너졌다)와 감독 평점을 따로 매깁니다. **"무너졌지만 명장"**과 **"지켜냈지만 오판"**이 성립합니다.

## 국면 5종

| # | 상황 | 목표 |
|---|---|---|
| 1 | 1-0 이기고 있음 · 후반 77분 | 리드 지키기 |
| 2 | 0-1 지고 있음 · 후반 78분 | 동점 이상 |
| 3 | 1-0 이기지만 경고 누적 · 후반 79분 | 리드 지키기 |
| 4 | 1-0 이기는데 우리 팀 퇴장 · 후반 80분 | 리드 지키기 |
| 5 | 0-1 지는데 상대 퇴장 · 후반 81분 | 동점 이상 |

현재 자동 검증을 통과한 국면은 5개입니다. 국면마다 쓸 수 있는 전술 레버와
교체 카드 수가 다릅니다. **한 국면에서 정답이었던 선택이 다른 국면에서는
오판이 되도록** 설계했습니다.

## 기술 구성

```
sim/       순수 함수 시뮬레이션 코어 (표현 계층에 비의존)
           rng · tactics · players · events · engine
render/    Canvas 2D
ui/        스코어보드 · 전술 레버 · 벤치 · 경기 분석
balance/   정책 봇 자동 검증 하네스
data/      국면 · 선수 · 코멘터리
```

Vite · React · TypeScript · Canvas 2D

**시뮬레이션 코어와 표현을 완전히 분리**했습니다. 덕분에 같은 엔진이 브라우저(게임)와 Node(자동 검증)에서 동일하게 실행되고, 경기를 화면 없이 여러 번 돌릴 수 있어 종료 후 **정답 경로와 내 선택을 나란히 재생**하는 것이 가능해집니다.

경기 진행은 결정론적입니다. 국면마다 시드가 고정되어 있고, 저장하는 것은 결과가 아니라 **결정 이력**(몇 번째 틱에 무엇을 했는가)이라 언제든 틱 단위로 완전히 동일하게 재현됩니다.

## 저작권 및 데이터 출처

- 등장하는 **국면·선수·수치는 전부 창작**입니다. 실제 경기의 복제가 아닙니다.
- **실존 선수의 이름을 사용하지 않습니다.** 선수는 등번호와 포지션으로만 식별합니다.
- 선수 사진 · 팀 엠블럼 · 유니폼 등 저작권 이미지를 일절 사용하지 않습니다. 원형과 등번호로만 표현합니다.
- 판정 및 코멘터리 문구는 개인이 아니라 상황 · 전술 단위로만 서술합니다.
- 외부 API를 호출하지 않습니다. 모든 연산은 클라이언트에서 수행됩니다.

사용한 서드파티의 라이선스는 [`LICENSES.md`](LICENSES.md)에 기록합니다.

### 밸런스 검증

엔진이 순수 함수라 브라우저 없이 Node에서 돌아갑니다. 국면마다 27가지 전술 조합을 400시드씩 전수로 돌려, 그 국면이 퍼즐로 성립하는지 자동으로 판정합니다.

```bash
npm run sim
```

```
■ 길이 막혔다  합격
   무개입 15.0% → 최선 38.6% (2/1/2)   격차 23.6%p   스프레드 33.5%p
   최하위: 0/2/0 5.1%

■ 잠긴 문  합격
   무개입 47.0% → 최선 71.0% (1/1/2)   격차 24.0%p   스프레드 24.0%p
   최하위: 0/0/0 47.0%

■ 한 명이 없다  합격
   무개입 38.2% → 최선 64.3% (1/2/2)   격차 26.1%p   스프레드 28.0%p
   최하위: 0/0/2 36.3%
```

합격 기준은 **무개입 50% 이하**(아무것도 안 하면 대체로 무너진다)와 **격차 20%p 이상**(제대로 하면 확실히 낫다)입니다. 미달인 국면은 튜닝하지 않고 목록에서 뺍니다 — 국면은 코드가 아니라 데이터라 빼는 비용이 0입니다.

이 스윕이 확인해 주는 것 세 가지입니다.

- **판마다 정답이 다르다.** 쫓는 판은 라인을 올려야 하고, 지키는 판은 올리면 안 됩니다. 최하위 조합도 판마다 다릅니다.
- **잠글수록 더 맞는다.** 세 국면 모두 최하위가 "수비라인 낮음"입니다. 내려앉으면 걷어내게 되고, 걷어내면 세트피스를 줍니다.
- **공짜인 선택이 없다.** 폭을 벌리면 공격 기회가 늘지만 중앙이 열리고, 압박을 올리면 공을 뺏지만 체력이 타고 경고 보유 선수가 퇴장당합니다.
