# 축구 사활

**결정론 엔진 위에서 도는 실시간 축구 감독 시뮬레이션**

바둑의 사활문제를 축구로 옮겼습니다. 창작된 경기 국면 하나를 주고, 경기
22분을 **실시간 75초**로 압축해 그 판을 타파하게 합니다.

> 후반 70분, 1-0으로 앞서는데 우리 팀 한 명이 퇴장당했다. 교체 카드는 2장.
> **이 판을 지켜낼 수 있는가.**

## 무엇이 다른가

**시계가 멈추지 않습니다.** 일시정지가 없고, 고민하는 동안에도 상대는
공격하며 우리 선수의 체력은 닳습니다. 멈춘 화면에서 최선을 고르는 것은
분석가의 일이고, 흐르는 경기에 개입하는 것이 감독의 일이라고 보았습니다.

**되돌릴 수 없습니다.** 교체 카드는 유한하고 회수할 수 없습니다. 내린
결정은 취소되지 않으며, 반영에 6초가 걸립니다.

**결과와 판단을 나눠서 채점합니다.** 축구는 확률 게임이라 옳게 판단하고도
무너질 수 있습니다. 그래서 경기가 끝나면 **같은 시드로 150판을 다시
돌려** 한 경기의 운을 걷어냅니다. 무개입·내 판단·권장 전술의 성공률을
나란히 놓기 때문에 **"무너졌지만 명장"** 과 **"지켜냈지만 오판"** 이
성립합니다.

## 한 판의 흐름

```
급수 타임 ── 시계 정지 ──▶ 재개 ── 실시간 75초 ──▶ 종료 ──▶ 사활 복기
지시는 여기서              시계는 여기서부터        결과      150판 비교
얼마든지                   멈추지 않음
```

킥오프 전 화면은 설정 메뉴가 아니라 **경기 안의 한 장면**입니다. 주심이
경기를 세우고 양 팀이 물을 마시는 급수 타임이며, 감독이 선수를 불러 모아
지시할 수 있는 몇 안 되는 순간입니다. 그래서 시작 전에는 다 만질 수 있고,
휘슬이 울린 뒤에는 시계가 멈추지 않습니다.

**모든 국면이 전반판과 후반판을 함께 가지며 고를 수 있습니다.**

```
전반   22:00 급수 타임 ─ 3분 ─▶ 25:00 재개 ─ 22분 ─▶ 47:00 전반 종료
후반   67:00 급수 타임 ─ 3분 ─▶ 70:00 재개 ─ 22분 ─▶ 92:00 경기 종료
```

전반을 고르면 후반으로 이어지고, 그 사이에 체력이 조금 돌아옵니다. 다만
바닥까지 뛴 선수일수록 덜 돌아옵니다 — 15분 휴식으로 돌아오는 피로와 안
돌아오는 피로가 다르기 때문입니다.

## 감독이 만질 수 있는 것

| | 무엇 |
|---|---|
| 선발 | 스물여섯 명 중 열한 명. 같은 포지션끼리 맞바꾼다 |
| 포메이션 | 9종 · 경기 중 실시간 변경 |
| 전술 프리셋 | 5종 — 균형 · 역습 · 측면 공략 · 전방 압박 · 밀집 수비 |
| 세부 레버 | 수비라인 · 압박 · 폭 각 3단계 |
| 선수 배치 | 44px 카드를 배치판 어디로든 드래그. 마우스가 없으면 3×3 버튼 |
| 개별 지시 | 5종 — 내려서라 · 올라가라 · 골문 앞 · 물러서라 · 아껴 뛰어라 |
| 교체 | 국면마다 2~3장 · 회수 불가 · 반영에 6초 |

선수를 앞으로 밀거나 옆으로 벌리면 **공격 기회와 역습 위험이 함께**
움직입니다. 자유 배치는 공짜 보너스가 아닙니다.

## 국면 5종

전부 자동 검증을 통과했습니다. 오른쪽 숫자는 **아무것도 하지 않았을 때의
통과율**이며, 기준팀(미국) 상대로 1,200시드를 실측한 값입니다.

| # | 국면 | 상황 | 목표 | 무개입 |
|---|---|---|---|---|
| 1 | 잠긴 문 | 1-0 앞서는데 앞 감독이 전원을 뒤로 내렸다 | 리드 지키기 | 49.5% |
| 2 | 길이 막혔다 | 0-1 뒤지는데 상대가 골문 앞을 촘촘히 막았다 | 동점 이상 | 10.9% |
| 3 | 경고가 쌓였다 | 1-0 앞서지만 경고를 안고 강하게 압박 중이다 | 리드 지키기 | 49.3% |
| 4 | 한 명이 없다 | 1-0 앞서지만 퇴장으로 열 명이다 | 리드 지키기 | 37.8% |
| 5 | 한 명이 많다 | 0-1 뒤지지만 상대가 열 명이다 | 동점 이상 | 18.3% |

**모든 국면은 앞 감독이 잘못 걸어둔 지시를 물려받습니다.** 중립 상태에서
시작하면 아무것도 안 해도 통과해 버리기 때문입니다. 첫 과제는 그것을
되돌리는 일입니다.

**한 국면에서 정답이었던 선택이 다른 국면에서는 오판이 되도록** 설계했습니다.

## 오늘의 상대 13개 팀

FIFA 랭킹을 참고한 13개 팀 중에서 고릅니다. 세기만 다른 것이 아니라
**하는 축구가 다릅니다.** 브라질은 등 뒤로 넘기는 비중이 스페인의 두 배가
넘어서, 같은 국면이라도 라인을 올리면 뚫립니다.

세기를 공격력과 수비력으로 나눈 것이 핵심입니다. 눈금 하나만 두면 아래
순위 팀은 위협도 적고 뚫기도 쉬워서 지키는 국면이 사라집니다.

기준팀은 미국이고 계수가 전부 1.0이라 완전한 항등입니다. **합격 기준선은
언제나 기준팀에서만 잽니다.** 다만 국면 카드에는 **고른 상대 기준의
통과율**이 뜹니다 — 열세 팀 × 다섯 국면을 전부 재서 넣었습니다.

상대 선수의 능력치와 주요 선수도 그 팀의 세기 계수에서 유도합니다. 표를
따로 두지 않으므로 계수를 조정하면 화면이 저절로 따라옵니다.

## 기술 구성

```
sim/       순수 함수 시뮬레이션 코어 (표현 계층에 비의존)
           rng · tactics · players · events · engine
render/    Canvas 2D 관전 연출
ui/        스코어보드 · 전술 레버 · 배치판 · 벤치 · 사활 복기
analysis/  경기 종료 분석 · 주장 브리핑 · 150판 비교
balance/   정책 봇 자동 검증 하네스
data/      국면 · 선수 · 코멘터리
```

Vite · React · TypeScript · Canvas 2D · 외부 API 없음

**시뮬레이션 코어와 표현을 완전히 분리했습니다.** `src/sim/` 은 `window`
와 `Date` 와 `Math.random` 을 일절 참조하지 않습니다. 덕분에 같은 엔진이
브라우저와 Node 에서 똑같이 돌고, 경기를 화면 없이 수천 번 돌릴 수 있어
종료 뒤 **150판 비교**가 가능해집니다.

경기 진행은 결정론적입니다. 매 틱 난수 18개를 고정된 순서로 소비하고,
저장하는 것은 결과가 아니라 **결정 이력**(몇 번째 틱에 무엇을 했는가)이라
언제든 틱 단위로 완전히 동일하게 재현됩니다. 종료 화면의 「같은 위기
다시」가 이 위에 서 있습니다 — 체력·경고·물려받은 지시·상대까지 전부
그대로고, 달라지는 것은 감독의 판단 하나뿐입니다.

## 저작권 및 데이터 출처

- 등장하는 **국면·선수·수치는 전부 창작**입니다. 실제 경기의 복제가 아닙니다.
- **실존 선수의 이름을 사용하지 않습니다.** 선수는 등번호와 포지션으로만
  식별합니다. `Player` 타입에 이름 칸 자체가 없고 테스트로 막아뒀습니다.
- 선수 사진 · 팀 엠블럼 · 유니폼 등 저작권 이미지를 일절 사용하지 않습니다.
  원형과 등번호로만 표현합니다.
- 상대 팀 이름은 국가명이며 순위는 FIFA 랭킹을 참고했습니다. 각 팀의 성향
  수치는 창작입니다.
- 판정 및 코멘터리 문구는 개인이 아니라 상황 · 전술 단위로만 서술합니다.
- 외부 API를 호출하지 않습니다. 모든 연산은 클라이언트에서 수행됩니다.

사용한 서드파티의 라이선스는 [`LICENSES.md`](LICENSES.md)에 기록합니다.

### 밸런스 검증

엔진이 순수 함수라 브라우저 없이 Node 에서 돕니다. 국면마다 27가지 전술
조합을 1,200시드씩 전수로 돌려, 그 국면이 감독의 판단을 실제로 요구하는지
자동으로 판정합니다.

```
■ 길이 막혔다    합격   무개입 10.9% → 최선 32.7%   격차 21.8%p
■ 잠긴 문        합격   무개입 49.5% → 최선 71.8%   격차 22.3%p
■ 경고가 쌓였다  합격   무개입 49.3% → 최선 74.0%   격차 24.8%p
■ 한 명이 없다   합격   무개입 37.8% → 최선 65.9%   격차 28.2%p
■ 한 명이 많다   합격   무개입 18.3% → 최선 43.4%   격차 25.1%p
```

합격 기준은 **무개입 50% 이하**(아무것도 안 하면 대체로 무너진다)와
**격차 20%p 이상**(제대로 하면 확실히 낫다)입니다. 미달인 국면은 튜닝하지
않고 목록에서 뺍니다 — 국면은 코드가 아니라 데이터라 빼는 비용이 0입니다.

이 스윕이 확인해 주는 것 세 가지입니다.

- **판마다 정답이 다르다.** 쫓는 판은 라인을 올려야 하고, 지키는 판은
  올리면 안 됩니다. 최하위 조합도 판마다 다릅니다.
- **잠글수록 더 맞는다.** 최하위가 대체로 "수비라인 낮음"입니다. 내려앉으면
  걷어내게 되고, 걷어내면 세트피스를 줍니다.
- **공짜인 선택이 없다.** 폭을 벌리면 공격 기회가 늘지만 중앙이 열리고,
  압박을 올리면 공을 뺏지만 체력이 타고 경고를 안은 선수가 퇴장당합니다.
